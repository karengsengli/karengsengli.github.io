# Thant Zin Myo - Professional Portfolio

A responsive static portfolio built with HTML, CSS and JavaScript.

## GitHub Pages

Publish this repository from the main branch, / (root), in Settings > Pages.
No build command or dependencies are required.

## Editing

- index.html: introduction, education, skills and contact
- experience.html: work experience page
- projects.html: project page and professional project summaries
- projects.js: university/personal project information and source links
- friendly.js: professional roles, project display, filters and dialogs
- friendly.css: typography, layout and themes
- assets/sources/: academic report PDFs prepared for sharing

Only portfolio assets are included. Original CVs, raw university records, development credentials and hosting service configuration are excluded.
